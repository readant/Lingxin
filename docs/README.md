## 📖 推荐学习路径

### 路径一：快速上手（想快速跑起来）

```
guide/01-快速入门 → usage/03-数据采集指南 → usage/04-模型训练
```

适合想快速体验项目功能、跑通流程的读者。

### 路径二：深入理解（想搞懂原理）

```
guide/01-快速入门 → design/02-架构设计 → design/05-核心代码导读 → design/06-设计模式实践
```

适合想深入理解系统设计、准备二次开发的读者。

### 路径三：问题排查（遇到问题来找答案）

```
dev/07-常见问题 → design/02-架构设计（查模块依赖）→ usage/04-模型训练（查训练参数）
```

适合遇到具体错误需要快速定位解决的读者。

### 路径四：参与开发（想贡献代码）

```
design/05-核心代码导读 → design/06-设计模式实践 → dev/08-测试指南 → dev/10-开发经验与踩坑记录
```

适合想参与项目开发、提交 PR 的贡献者。

## 🎓 新手学习教程

项目提供 `learning/` 目录下的13阶段学习教程，从零基础到项目实战：

| 阶段 | 内容 | 适合人群 |
|------|------|----------|
| 0-1 | 环境配置 + Python基础 | 🟢 零基础 |
| 2-3 | OpenCV + MediaPipe入门 | 🟢 初学者 |
| 4-5 | 手部/姿态检测 | 🟡 有基础 |
| 6-7 | NumPy + 特征工程 | 🟡 有基础 |
| 8-9 | SVM + LSTM模型 | 🔴 进阶 |
| 10 | 数据采集实战 | 🔴 贡献者 |
| 11-13 | 配置管理 + 训练流程 + 数据增强 | 🔴 贡献者 |
